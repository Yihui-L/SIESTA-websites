SIESTA 的物理原理

SIESTA 在给定的三维背景网格上求静态 MHD 平衡。它以 VMEC 平衡为初态，通过理想位移迭代降低力残差，并在启用非理想步骤时允许磁场线重联，因此可以求得含磁岛和随机磁场区的平衡。

1. 背景坐标与边界

网格由 VMEC 的几何映射给出，径向采用 ρ=s，其中 s 是 VMEC 的归一化环向磁通。极向角 u 和环向角 v 上作 Fourier 展开，径向用交错的全网格和半网格作差分。几何、位移与力使用全网格，磁场和压强主要在半网格上推进。求解期间背景网格和度规固定，更新后的磁场可以穿过 ρ=const. 面。因此，ρ 标记的是背景坐标面，最终磁拓扑由求得的磁场决定。

固定边界模式将初始 VMEC 等离子体边界作为计算外边界。自由边界模式把网格延伸到初始等离子体外，并用 BMW/PCHELMS 和线圈数据初始化外部磁场。外层计算边界由壁面几何及网格外扩设置确定，等离子体边缘可在计算域内随平衡改变。 Hirshman 等，2011，第 III–VII 节 · Peraza-Rodriguez 等，2017 · 边界输入

自由边界初始化在扩展网格上求解 ∇×∇×A = μ₀J_VMEC，再用离散旋度得到磁场。计算壁的矢势边值包含等离子体和外线圈贡献。安培方程的电流源按当前 Fourier 表示满足离散相容条件，原 LCFS 外的源为零。该零源条件用于初始化。带衰减压力尾的外区随后的平衡仍可具有有限电流。计算壁固定后，最后一个物理压力半网格仍位于壁内并参与迭代。若把计算壁设为零压且磁力线穿到该壁，静态平衡的 B·∇p = 0 要求沿该线压力为零。验证这种拓扑相容性需要实际追踪到计算壁。 自由边界论文 · 矢势初始化

2. 力平衡与能量变分

静态、标量压强的 MHD 模型要求洛伦兹力与压强梯度平衡，同时满足安培定律和磁场无散条件。以下公式采用 SI 单位。当前源码固定 γ=5/3。内部磁场乘 b_factor，压强先乘 μ₀ 再乘 p_factor=b_factor²，因此内部力算子不显式写出 μ₀ 与下列 SI 形式相容。模型常数 · 初态归一化

𝐅=𝐉×𝐁−∇p=0,μ0𝐉=∇×𝐁,∇·𝐁=0

将磁能和绝热内能相加得到势能 W，其中 γ 是绝热指数。对满足边界条件的理想位移 𝝃 取变分。在边界项消失时，分部积分给出

W=∫V(B22μ0+pγ−1)dV
δW[𝝃]=∫V(𝐁·δ𝐁μ0+δpγ−1)dV=−∫V𝝃·𝐅dV

因此，对所有允许位移满足 δW=0 时，域内的力平衡条件是 𝐅=0。平衡方程沿磁场投影还给出 𝐁·∇p=0，即压强沿每条磁力线为常数。若磁力线在连通区域内稠密且压强连续，则该区域的压强趋于平坦。 Hirshman 等，2011，第 II、IV–V 节

3. 理想更新与线性化位移

在当前状态上施加小位移 𝝃。磁通冻结和绝热压强方程给出 Euler 磁场、压强增量。压强的两项分别来自对流和压缩。

δ𝐁I=∇×(𝝃×𝐁)
δp=−𝝃·∇p−γp∇·𝝃

将增量代入力残差，保留位移的一阶项，得到线性力算子 L。

L[𝝃]=δ𝐅=∇×δ𝐁Iμ0×𝐁+𝐉×δ𝐁I−∇δp

每轮用预条件求解近似满足 L[𝝃]≃−𝐅 的位移。SIESTA-lyh 使用物理预条件和 GMRES 求候选位移，并用更新后的磁场和压强重新评估非线性残差。单步磁场与压强仍使用一阶增量。非线性力残差用更新后的场重新计算，因此包含更新后电流与磁场的完整乘积。 Hirshman 等，2011，第 V、IX 节 · 位移求解与残差搜索

理想步显式重算零位移的基准残差，并在同一力算子设置下检查候选。接受步要求重算的非线性力残差下降，且原生物理半网格的压力满足舍入容差。自由边界在每个角向间隔细分四份的嵌套网格上重构谱压力。根据投影后的压力增量及角向区间内的压力下界，计算所有 MPI 分区共同的保守可行步长区间。当原方向受近零压强径向层限制时，另试满足壁面位移条件的备选方向。没有可接受步时保留当前状态。 理想步搜索 · 物理压力检查

4. 人工电阻与磁拓扑变化

理想扰动关系来自连续方程的磁通冻结。人工电阻通过 Faraday 定律加入非理想磁场增量，使共振电流层能够扩散并改变磁连接。SIESTA-lyh 的常规扩散分支使用与电流成正比的电场，径向窗口 w(ρ) 控制扩散分布。

Eη=ηnumw(ρ)𝐉,Δ𝐁η=−Δτ∇×Eη

开启 LRESISTIVE 时，代码在提交理想步后，按预条件阶段和力残差决定是否扩散。触发后将位移置零，执行 10 个显式磁场子步，各子步根据更新后的磁场重算电流，压强在此阶段保持不变。扩散后重算非线性力残差，新的磁场进入下一轮理想位移求解。ETA_FACTOR 控制数值扩散强度，Δτ 表示迭代中的伪时间步。 Faraday 更新 · 扩散子步

普通磁扩散的连续磁能变化率为 −∫η|J|² dV，边界无切向电场功。显式离散按整组磁能及残差检查并在必要时回退减步。磁场变化后，力残差仍可能升高。 扩散步控制

程序还可通过 LADD_PERT 与 HELPERT 在背景共振面附近施加局域螺旋种子。对于相位为 mu+nNfpv 的模态，背景旋转变换满足 mι+nNfp=0 处发生共振。该分支用沿磁场的局域电场产生初始拓扑扰动，按试探能量选择径向宽度。后续平衡由完整迭代得到。 Hirshman 等，2016，第 3–4 节 · 共振种子实现

当前实现以一阶场增量推进有限位移，并使用离散差分与谱截断；因此不能把连续理想方程的磁通冻结理解为有限步数值更新精确保持所有磁拓扑不变量。常规电阻子步只更新磁场，不加入焦耳加热的压力演化；这里的伪时间及人工电阻用于平衡搜索，不能据此解释真实电阻 MHD 的时间演化。磁场与压力更新 · 电阻子步

5. 如何判断求得平衡

当前实现用 F2(MHD) 衡量力平衡，它是离散、归一化的体积加权力残差平方。程序按 FTOL 检查残差，并受 NITER 步数上限约束。理想步按非线性残差评估候选，能量变分给出力算子的物理形式，程序同时记录每步能量。逐步 δW<0 并非接受条件。达到残差容差表明离散力平衡达到目标精度，理想稳定性还需单独检验能量的二阶变分。 力残差计算 · 迭代与停止条件 · 验证范围

力残差达到容差后，仍需检验网格与谱截断收敛、磁场无散性、边界和磁通约束，以及磁岛结果对种子幅度和人工电阻的敏感性。已有研究报告磁岛尺寸及位置会随输入扰动幅度改变，故单次力平衡收敛不能证明磁岛宽度唯一或与扰动无关。Woodbury Saudeau 等，2026

输入、计算与输出

SIESTA-lyh 的主程序 xsiesta 由 Fortran 实现。一次运行从 VMEC 平衡或已有 SIESTA 检查点建立初态，以力残差衡量平衡迭代，写出 NetCDF 检查点与诊断文件。

输入 Input

在算例目录准备含 &SIESTA_INFO 的 siesta.jcf，并按边界与重启模式准备数据文件。

计算 Process

构造或恢复计算网格与场量，计算 MHD 力残差，按设定进行预条件迭代。

输出 Output

用 siesta_<RESTART_EXT>.nc 读取已保存状态，用 output_*.txt 查看运行过程与残差。

从初态到平衡迭代

  1. 首次运行将 VMEC 初态映射到 SIESTA 网格。自由边界再构造外壁以内的外扩网格，并通过 BMW/PCHELMS 求初始外场。重启则直接恢复检查点中的网格、几何和场量。
  2. 计算离散 MHD 力残差，先进入对角预条件阶段，再根据残差和剩余步数进入块预条件阶段。LADD_PERT、LRESISTIVE 控制种子扰动和电阻更新。
  3. 用日志中的 F2(MHD) 核对 FTOL，并结合 NITER 判断是达到容差还是用完迭代步数。仓库的四组 W7-X 示例均设置 NITER=100，各例记录实际停止原因。

改动清单

平衡演化与预条件器

  • 自由边界人工电阻窗口。update_bfield 在普通外扩网格上使用覆盖全域的非负窗口，避免沿用等离子体归一化后，ρ>1 使 ρ2(1−ρ) 变为负值。对全网格节点 j<Ns−1 使用 qj2(1−qj)，其中 qj=(j−1)/max(1,Ns−2)。外壁最后两个全网格节点的窗口及电场置零，使末端半网格的电阻旋度增量为零。自由边界螺旋种子保留原有内区窗口，并将壁面旋度模板对应的最后两个全网格节点电场置零。实际磁场更新算子测试中，螺旋种子的壁面三个谱分量增量均为零，代表性环向增量从 6.095679×10⁻² 降为零。固定边界及远离壁面的对照切片逐值一致。制造场在实际径向差分下的磁能方向导数由 +5.626736 变为 −0.641580，外壁磁场增量模由 7.390625 降为 0。验证覆盖该制造场的离散电阻子步。siesta_bfield.f90
  • 电阻扩散后的残差与步长。以当前接受态为起点试探十个显式子步，检查整组后的磁能和力残差。接受条件要求磁能在舍入误差内不增加，且 F² 至多为扩散前的四倍。试探失败恢复原磁场谱，减半系数后重试，最多 8 次。全部失败则跳过本组并重算恢复态的残差。一次接受后的系数增幅至多 10%，回退后接受的系数沿用到下一组。该控制限制已接受的整组扩散，仍允许有限的力残差升高。 扩散步控制
  • 力残差停滞与 LM 阻尼更新。init_evolution 每次初始化时清零 failed_min_count，防止连续调用继承停滞计数。连续三次残差未下降时，evolve 的高、低残差分支均以 MIN(3 × 当前值, 上限) 截断阻尼增长。对照测试覆盖重复初始化和触及上限的情况。初始阻尼 0.001 的一次更新从原版的 10⁹ 修正为 0.003。演化提交前检查残差、能量和位移范数，拒绝非有限值。由对角预条件切换至块预条件时，如果下一步正好等于 NITER，仍执行最后一步。双 rank 测试覆盖该切换和 NaN 拒绝路径。evolution.f90 阻尼插值仅在目标容差严格小于过渡残差 10⁻⁶ 时进行，避免合法 FTOL=10⁻⁶ 使分母为零；更松目标保留输入阻尼，低于严格目标的残差使用最小阻尼。普通区间保留原算术。使用同一检查点与输入，复测确认该容差触发的 DMINL=NaN 已消除。 零位移为搜索基准，只有压力可接受且力残差下降的试探才提交，并以选中位移重算谱增量和残差。原例程在全部试探升高残差时曾返回非零位移并报告零位移残差。当前制造反例返回零位移和重算一致的残差。初态和重启同样检查物理压力。初态已达到 FTOL 时，跳过为阶段切换预留的第二个对角步。 步长搜索
  • 自由边界理想步的压强可行性。原搜索只缩短同一个方向。一个贴壁半网格的压强已接近下限且仍将下降时，整域位移可能连续被拒。自由边界以实际 Fourier 投影后的压力增量与现态计算可行步长区间。以谱系数绝对和约束雅可比加权压力的角向二阶导数，再用双线性插值误差上界扣除样点间余量。在雅可比保向的前提下，检查覆盖整个角向区间并允许舍入尺度的误差，径向仍在物理半网格层验算。若原方向只允许很小的步长，沿限制层局部平滑衰减位移，并试探受限层两侧整网格位移行均为零的备选方向。短步仍受限时，将现态力平滑衰减至原 LCFS 为零，试探该内部方向和其反向。这些操作只用于生成候选，原理想压力、磁场更新算子和外壁位移条件沿用。共轭梯度的候选也经同一搜索验收，只有满足压力检查且降低完整非线性力残差的候选才提交。 可行区间及备选方向 · 共轭梯度验收

  • 普通三维 Fourier 并行和计时。正、逆变换的二维计算核接受显式工作区，三维接口按独立径向切片静态分配任务。线程各自使用临时数组，读取共享三角表，写入各自的切片。切片数至少为 4 且 切片数 × NU × NV ≥ 4096 时可启用多线程，团队规模最多为切片数的一半。全程计时在并行区外更新。DIAGONALDONE && INHESSIAN 路径的子阶段时间计入对应计时项，全程时间只累加一次。单元测试对照 8 个不同切片与串行二维接口，覆盖两种奇偶性、角向一阶和混合导数及累加模式。fourier.f90

  • 压力、扰动场与力算子工作区。压力算子用既有物理空间数组保存半网格速度，顺序复用谱空间工作区，并让径向梯度直接写入目标数组。IncFields 将四个顺序使用的谱空间临时数组合为一个。GetMHDForce 在角向压力梯度用完后，复用谱数组计算径向梯度。这样减少分配和整数组复制，并保持原有网格转换、边界处理和运算顺序。siesta_pressure.f90 · siesta_force.f90

  • 平衡 GMRES 候选解与矩阵向量乘法工作区。候选解与反向通信回调的模块工作数组使用独立存储。以返回候选重新计算实际非线性力残差，涵盖不执行非线性预览的模式。检查输入、输出和残差的有限性，并对非法求解状态报错。Krylov 子空间维数不超过方程数。54 个未知量的三步 Debug 算例在 1、2、4 rank 上给出一致的逐步 F2。并行 gmres_wrap 为每次线性求解分配一次全长缓冲区，供本次 matvec_par 回调复用。每次回调仍清零缓冲区、填入局部输入并执行原 halo 交换。求解退出时恢复先前指针关联并释放缓冲区。独立回调和尺寸不匹配时使用局部分配。以制造算子和通信替身调用实际例程的测试覆盖 3 次求解、14 次回调，包括地址复用、清零、尺寸变化及指针生命周期。gmres.f90 删除线性矩阵向量乘积的固定绝对截零，使小幅模态参与 Krylov 求解。LIBSTELL 的串行和并行 GMRES 从真实试探残差选择最优候选，收敛进度以乘法比较，避免除零。并行零右端在全部 rank 收到范数后统一返回，含无本地方程的 rank。 依赖兼容构建

  • MPI/OpenMP 初始化、线程配置与编译开关。程序在 BLACS 初始化前请求 MPI_THREAD_FUNNELED，或查询已有 MPI 环境的支持级别。MPI 调用仍由初始化线程执行，外部拥有的 MPI 环境由调用者结束。MPI_THREAD_SINGLE 自动退回单线程。OMP_THREADS 控制每个 rank 的线程数，程序结合可见 CPU、节点内 rank 数、/sys/fs/cgroup/cpu.max 和线程上限设置团队，并输出 CPU team。CMake 的 SIESTA_ENABLE_OPENMP 默认开启，可用 OFF 选择串行 Fourier。编译器缺少 Fortran OpenMP 支持时同样使用串行路径。prof_mod.f90 · blocktridiagonalsolver_s.f90 · siesta_namelist.f90 · siesta_run.f90 · CMakeLists.txt ScaLAPACK 的三个 BLACS 网格从调用者指定的 MPI 通信器创建。析构逐个释放网格并在所有 rank 清理统计缓冲，调用者已有的 BLACS 网格可继续通信。四个 MPI rank 中使用逆序的双 rank 子通信器，再切换为四 rank，可正常完成。原实现在子通信器调用上挂起。上下文结束时恢复调用者的 OpenMP 线程数和动态团队设置。径向与谱空间映射在每次运行重建；MPI 缓冲先解除挂接再释放，分区合法性由所有 rank 一致检查。量场清理依据各组实际分配状态，避免对称性切换或改变网格后复用旧数组。双 rank 外部 MPI 测试在同一进程内先后初始化 49 层和 53 层 NCSX，验证了映射与线程恢复。 MPI 映射 · 量场清理 自动资源识别当前读取可见 CPU 和 cgroup v2 根路径 cpu.max；未覆盖 cgroup v1 及所有祖先配额。MPI rank 数由启动器决定。用户仍应按调度器分配绑定 CPU；这里不宣称完整求解加速或最优资源选择。

测试和诊断工具

  • 运行计时与 MPI 统计。每个运行上下文重置累计计时器及 Fourier 所用的阶段标志。状态更新时间只计一次，跨 rank 最大耗时使用实际测量值，Hessian 非对称性最小值使用最小值归约。双 rank 计时探针验证了清零与极值。 计时器 · MPI 统计 · 状态更新 profiling 栈配对错误或找不到标签时通过已有 MPI-aware 断言失败，避免字符 STOP 返回成功。对实际模块调用 profstart(outer)/profend(wrong)，退出码由 0 修正为 1。

  • Hessian 非对称性与分布式缩放统计。非对称性指标按完整矩阵的 ‖A−Aᵀ‖F/‖A‖F 定义，同时计算每对上、下非对角块的贡献。串行、ScaLAPACK 和块循环实现统一修正；制造矩阵 [[1,3],[1,2]] 的结果由 0.5163977795 恢复为 sqrt(8/15)=0.7302967433。零矩阵统一返回未定义指标标记 −1，避免除零。ScaLAPACK Hessian 的双元素极值归约包含 maxeigen：双 rank 的旧值 2/20 统一为 20/20；该统计量不作为已验证的谱上界。列缩放数组先读后写，接口改为 INTENT(INOUT)，消除读取入口未定义值的 Fortran 契约问题。非单位缩放累乘测试通过，旧 GNU 构建在该测试中也碰巧给出正确数值。check3d.f90 · 块循环实现 · Hessian

  • 回归算例与产物依赖。CTest fixtures 要求 VMEC 和 SIESTA 的产物生成测试成功后才运行比较器。MPI 套件显式注册 1、2 rank，保留同一目录内先比较再覆盖产物的顺序。预置旧重启后故意使 SIESTA 初始化失败，压力比较被 CTest 标为 Not Run。测试公共配置 · 初始化 · 非对称 · 终态 · 稀疏 · MPI 15 项实际执行磁场比较、却命名为 jksup* 的检查改名为 jbsup*_secondary_test；比较对象、采样与容差保持原值。这些检查不能用作电流回归证据。把命令直接换成电流后超差，也不足以认定求解器有 bug，因为初始化的表示投影、离散微分及后续理想迭代都可能改变这个对照，原磁场容差从未被验证为电流容差。共振定位单元测试失败时使用非零停止码，避免字符 STOP 被 GNU Fortran 记为成功。 100 层标准算例最多使用 8 个 MPI rank，避免主机的默认进程数超出小网格的径向分区能力。专用 MPI 对照按显式的 1、2 rank 运行。

  • 回归工具的半网格径向导数。全网格第 i 点使用两侧半网格的 [qi+1−qi]/h，修正原差分错位一个径向点并读取轴端无效槽的问题。新增 CTest 用 3、9、65 点网格上的二次剖面验证内部导数，轴端槽特意设为 NaN。这个修复作用于结果比较器中的径向导数与磁场散度重构。grid_quantity.cpp · 制造解回归 · 注册配置

  • 回归比较器的输入校验与错误报告。一维比较器在 failed at s = 后输出实际采样坐标。读取 NetCDF 时检查文件、变量、形状和读取状态，比较时拒绝非有限值和默认填充值。两个精确零值的相对误差记为零。未知测试名、缺失参数和缺失数据以非零状态退出，保留有效算例原有采样和容差。实测覆盖上述三种错误以及零电流相对比较。比较器 · 命令行解析 · 解析入口 · NetCDF 读取 · SIESTA 字段 · VMEC 字段 非 dump 比较要求 -tol 有限且为正；径向采样必须满足 0≤-min≤-max≤1，显式提供的角度必须有限。在 [2,3] 采样时，旧插值器将两份数据都截在端点，可能错误报告通过；现在在读取数据前拒绝越界采样。原有有效测试的采样规则和容差不变。

编译与运行

在已配置依赖的 Stellarator-Tools 构建中，将 SIESTA 子项目指向 SIESTA-lyh/。

需要 CMake 3.19 或更新版本。CMake 从关联的 LIBSTELL 源目标生成 GMRES 和 NetCDF 字符串读取的兼容副本，在构建目录编译这两份副本，原依赖源码无需手工编辑。WOUT 字符串按文件长度和接收缓冲区长度的较小值读取并补空格。已验证的 LIBSTELL 基线为 cacea89。无法识别的依赖实现会在配置阶段报告。 依赖兼容构建

cmake -S /path/to/Stellarator-Tools -B /path/to/build \
  -DBUILD_SIESTA=ON -DCMAKE_BUILD_TYPE=Release -DSIESTA_ENABLE_OPENMP=ON \
  -DFETCHCONTENT_SOURCE_DIR_SIESTA=/absolute/path/SIESTA-websites/Source-Code/SIESTA-lyh
cmake --build /path/to/build --target xsiesta -j 8

从算例目录启动。xsiesta 无参数时读取 siesta.jcf，xsiesta case 读取 siesta_case.jcf。相对路径以工作目录为准。WOUT_FILE 指向已有 VMEC 输出，文件名使用 wout_*.nc。下面命令使用一个 MPI rank 和一个线程。W7-X 输入、输出与运行说明

cd /path/to/case
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 OPENBLAS_DEFAULT_NUM_THREADS=1 \
MKL_NUM_THREADS=1 mpirun -np 1 /path/to/build/_deps/siesta-build/xsiesta

OMP_THREADS 是 &SIESTA_INFO 中的非负整数。正值优先指定团队规模。默认 0 优先采用 OMP_NUM_THREADS，否则按进程可见资源自动选择，最多 4 线程。兼容环境变量 SIESTA_CPU_THREADS 可在自动分支中提供候选值，仍受 4 线程上限约束。实际团队受资源限制和 OMP_THREAD_LIMIT 约束，小型 Fourier 调用可以使用更少线程。MPI rank 数和核绑定由启动命令或调度器指定。线程配置实现 · Open MPI 绑核说明

验证范围

本节保留有明确输入、预期结果和通过判据的定向检查。多步演化中的力残差、压力剖面和迭代接受率随初态、物理模型和离散设置共同变化，用于分析算例表现。

  • 离散算子与求解器。在给定位移下，将线性化和非线性力算子及压力扰动分别与基线对照，覆盖对称与非对称场、不同 MPI rank 和 OpenMP 线程。制造测试检查 Fourier 正逆变换、半网格导数、GMRES 精确零残差，以及两种块求解后端对混号对角元的处理。
  • 理想步与扩散保护。用制造反例核对压力不合格时的拒绝路径、零位移返回，以及返回位移与重算残差的一致性。强制触发扩散保护时，核对拒绝后的减半重试与直接使用减半系数的结果，以及全部试探失败后的状态回滚。
  • 初始化与重启。用 NITER=1 检查首次位移前的 WOUT 压力读入与网格映射，并检查固定边界 λ 重算。自由边界初始化以实际离散安培方程的回代残差验收，另用受限求解预算核对拒绝路径。重启测试核对场谱、压力、磁通和残差读回，并用已知剖面及模式表检验径向重采样与跨 NFP 谐波映射。
  • 输入输出与并行入口。检查非法网格、缺失文件和字段、非有限值以及空 MPI 输出分区。用成对运行核对输出开关对已保存状态的影响，并检查调用方 MPI 生命周期和 OpenMP 设置恢复。当前验证覆盖 Release、带运行时检查的 Debug 和关闭 OpenMP 的构建。
  • 数值库对照。在同一 49 阶制造矩阵上比较 OpenBLAS DGETRF 的分解与求解误差。对 AutoDL OpenBLAS 0.3.20，Cooperlake 内核曾在 INFO=0 时返回错误分解。Haswell 内核和独立 Netlib 对照的最大解误差均不超过 3.33×10⁻¹⁶。
